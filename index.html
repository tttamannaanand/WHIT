Inside the app

How it's built

Expo + TypeScript

React Native app in strict TypeScript, with onboarding, lessons, quizzes, archive and profile screens.

RevenueCat

whit_pro entitlement with Monthly, Yearly (7-day trial) and Lifetime packages, kept in sync by webhooks.

Server-side paywall

The Express API re-checks the entitlement with RevenueCat before serving any past lesson, so a modified client can't unlock the archive.

Run it yourself

git clone https://github.com/tttamannaanand/WHIT.git && cd WHIT
cd backend && cp .env.example .env && npm install && npm run seed && npm start
cd ../app && npm install && npx expo start

Full setup, including the RevenueCat dashboard steps, is in the README.
